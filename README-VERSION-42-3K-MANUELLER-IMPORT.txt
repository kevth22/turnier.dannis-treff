Dart11en – Version 42: Manueller 3K-Tabellenimport

- Automatischer 3K-Sync im Kader wurde durch manuellen Copy/Paste-Import ersetzt.
- Admin/Captain: "3K importieren" im Spielerprofil.
- Liga auswählbar: Ruhrpott / Herne.
- Datenart auswählbar: Bestleistungen / Spielstatistik.
- Ganze sichtbare 3K-Tabelle kopieren und in das Textfeld einfügen.
- Vorschau vor dem Speichern zeigt zugeordnete und nicht zugeordnete Namen.
- Spielerzuordnung primär über Vorname + Nachname, Spitzname nur Fallback.
- Bestleistungen: 180, Highscore, Highfinish, Short Game.
- Spielstatistik: Spiele gewonnen/verloren, Legs gewonnen/verloren.
- Ruhrpott und Herne werden getrennt gespeichert und anschließend zusammengeführt.
- Erneuter Import einer Liga ersetzt nur den Stand dieser Liga.
- Cloudflare-Worker bleibt für Push-Benachrichtigungen unverändert nutzbar.
