Dart11en – 3K Import Alias-Zuordnung

- Nicht zugeordnete 3K-Spieler können direkt in der Import-Vorschau einem Dart11en-Profil zugeordnet werden.
- Die Zuordnung wird als threeKAliases im Mitgliedsdokument gespeichert.
- Danach wird die Vorschau sofort neu berechnet.
- Bei späteren Importen wird der Alias automatisch erkannt.
- Vorname + Nachname bleibt weiterhin der primäre automatische Abgleich.
