2. Erhebung und Speicherung personenbezogener Daten

Bei der Anmeldung zum Dartturnier werden personenbezogene Daten erhoben. Hierbei handelt es sich insbesondere um den angegebenen Namen sowie die Zeit der Anmeldung.

Diese Daten werden ausschließlich zur Organisation und Durchführung des Turniers verwendet.

3. Speicherung der Daten

Die eingegebenen Daten werden in einer Datenbank gespeichert (Firebase/Google Firestore), um eine Warteschlange, Teilnehmerverwaltung und Turnierorganisation zu ermöglichen.

Die Speicherung erfolgt nur so lange, wie es für die Durchführung des Turniers erforderlich ist.

4. Verwendung der Daten

Die Daten werden ausschließlich für folgende Zwecke genutzt:

  • Verwaltung der Warteschlange
  • Zuweisung von Teilnehmerplätzen
  • Organisation des Turniers
  • Anzeige des Turnierstatus

5. Weitergabe von Daten

Eine Weitergabe personenbezogener Daten an Dritte erfolgt grundsätzlich nicht, außer dies ist zur Durchführung des Turniers erforderlich oder technisch bedingt.

Dies betrifft insbesondere:

  • Hosting der Website über GitHub Pages
  • Speicherung der Daten über Firebase (Google)

6. Zahlungsabwicklung (PayPal)

Die Zahlung des Startgeldes erfolgt über den Zahlungsdienstleister PayPal.

Bei Nutzung von PayPal werden Daten direkt an PayPal übermittelt. Es gelten die Datenschutzbestimmungen von PayPal:

https://www.paypal.com/de/webapps/mpp/ua/privacy-full

Wir selbst speichern keine vollständigen Zahlungsdaten.

7. Streaming und Veröffentlichung

Während des Turniers können Spiele aufgezeichnet oder live gestreamt werden.

Mit der Teilnahme am Turnier erklärst du dich damit einverstanden, dass dein Name sowie ggf. Bildmaterial im Rahmen des Turniers verwendet werden.

8. Rechte der betroffenen Personen

Du hast das Recht auf:

  • Auskunft über deine gespeicherten Daten
  • Berichtigung falscher Daten
  • Löschung deiner Daten
  • Einschränkung der Verarbeitung
